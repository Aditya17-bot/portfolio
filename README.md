# Aditya Sridhar — portfolio

Personal site: models trained from scratch and runnable in the browser, research, patents, open-source work.

## Develop

```bash
npm install
npm run dev          # http://localhost:3000
npm run check        # typecheck + lint + build + Playwright smoke tests
```

Stack: Next.js (App Router), TypeScript, CSS Modules with design tokens in `src/app/globals.css`.
